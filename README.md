# IT Support Ticket Management System

A simple IT Support Ticket Management System built using Linux Shell Scripting, SQL, Git, and GitHub.

## Project Overview

This project is designed to manage employee IT support tickets.

It allows users to:

- Create support tickets
- Store ticket information
- Check ticket status
- Generate ticket reports
- Manage ticket data using SQL
- Track project changes using Git and GitHub

## Technologies Used

- Linux / Git Bash
- Shell Scripting
- Oracle SQL
- Git
- GitHub
